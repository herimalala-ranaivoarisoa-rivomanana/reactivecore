# Security policy

Report suspected vulnerabilities privately using the repository's [private vulnerability reporting form](https://github.com/herimalala-ranaivoarisoa-rivomanana/reactivecore/security/advisories/new). If GitHub does not offer private reporting, contact the repository owner through a private channel before sharing technical details. Include the affected version, impact, and enough context for the maintainer to investigate. Keep credentials and personal data out of the report.

ReactiveCore is currently an alpha. Apply security fixes from the latest available alpha and follow the release notes when upgrading.
