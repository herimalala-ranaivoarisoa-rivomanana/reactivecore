# API ReactiveCore

Cette application NestJS charge les fonctions d’un projet, expose l’API HTTP/SSE et héberge les moteurs de requêtes et de mutations. La CLI du dépôt configure le module du projet, sa connexion PostgreSQL et son canal de notifications.

Consultez la [documentation principale](../../README.md) pour provisionner et lancer un projet ou exécuter ses vérifications.
